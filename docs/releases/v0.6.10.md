# WebSnapshot v0.6.10 – Links-pro-Seite-Limit und Navigation

**14. Oktober 2026**

## Konfigurierbares Links-pro-Seite-Limit

Unter **Einstellungen → Crawl-Grenzen und Geschwindigkeit** kann neu das Limit für die Anzahl weiterverfolgter Links einer einzelnen HTML-Seite eingestellt werden.

- **Standardwert: 1'000 Links pro Seite**, bisher fest 300.
- **Einstellbereich: 1–10'000** Links pro Seite.
- Die Einstellung wird global in SQLite gespeichert und beim Start eines Hintergrundjobs festgehalten. Bereits laufende Jobs übernehmen geänderte Einstellungen nicht.
- Die Grenze greift sowohl bei statischen als auch bei browsergerenderten HTML-Seiten, nachdem die erlaubten Links anhand des Crawl-Bereichs gefiltert wurden.

## Welche Links wurden ausgelassen?

Bisher enthielt die Warnung lediglich die Gesamtzahl. Für **nach dem Update gestartete Snapshots** werden nun zusätzlich die ausgelassenen URLs und die jeweilige Quellseite gespeichert.

Unter **Snapshot-Verwaltung → Crawl-Diagnose** stehen zur Verfügung:

- Zahl ausgelassener URLs und Zahl betroffener Quellseiten;
- eine durchsuchbare Tabelle mit «Quellseite», «Nicht weiterverfolgte URL» und «Grund»;
- CSV-Export in Blöcken zu höchstens 10'000 Datensätzen.

Die Tabelle lädt maximal 200 Zeilen zugleich, um grosse Snapshots nicht auszubremsen. Während des Crawls werden die Einträge speicherschonend in einer temporären Datei gepuffert und beim Speichern des Snapshots in die SQLite-Tabelle `crawl_link_exclusions` übernommen. Das Protokoll wird beim Löschen des zugehörigen Snapshots oder der Website mit gelöscht.

**Einschränkung:** Für bestehende Snapshots können die früher nicht gespeicherten Einzel-URLs nicht rückwirkend ermittelt werden. Bricht ein Prozess vor dem Speichern des Snapshots ab, sind die temporär gesammelten Informationen ebenfalls nicht garantiert verfügbar.

## Navigation und verfügbare Breite

- Eine eigene Schaltfläche oben im Menü schaltet zwischen breiter Navigation und einer **schmalen Icon-Leiste** um. Die Icons bleiben als Navigationsbuttons nutzbar.
- Die Webseiten-Auswahl steht wieder als **Dropdown unter «Übersicht»**. In der schmalen Leiste ist sie über das 🌐-Symbol als Popover erreichbar.
- Das Website-Dropdown verwendet beim Umschalten dieselbe Sitzungsvariable; die gewählte Website bleibt erhalten.
- Die zuvor global erzwungene Seitenleisten-Mindestbreite von 20 rem wurde entfernt, damit der Hauptinhalt den frei werdenden Platz nutzen kann.
- **Im ausgeklappten Menü keine Navigations-Tooltips.** Im kompakten Modus erscheint der jeweilige Seitenname bei Hover oder Tastaturfokus **rechts neben dem Icon-Button**.
- Die seitliche Tooltip-Position wird über CSS umgesetzt und muss auf dem lokalen Windows-Browser optisch geprüft werden. Je nach Streamlit-Version können sich interne DOM-Klassen ändern.

## Qualitätssicherung

Automatisierte Tests kontrollieren den Standardwert, die zulässigen Einstellbereiche, die Zuordnung ausgelassener Links zu Quellseiten, Datenbankpersistenz, Suche, CSV-Export sowie die Struktur des kompakten Navigationsmenüs und die Tooltip-Position.

Die Navigation ist eine Streamlit-Weboberfläche. Ein vollständiger interaktiver Browser-/Windows-Test der schmalen Sidebar und der Tooltip-Darstellung wurde noch nicht ausgeführt.

## Windows-Update

Laufende Crawl-Jobs abschliessen und WebSnapshot beenden, dann:

```cmd
cd /d S:\_ChatGTP\WebSnapshot\websnapshot
git pull
.venv313\Scripts\python.exe -m pip install -e ".[dev]"
```

Anschliessend `WebSnapshot.bat` erneut starten. Bestehende Snapshots bleiben erhalten. Weitere Einträge in [CHANGELOG.md](../../CHANGELOG.md).
